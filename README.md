# MSSC Brewery
# Overview
The MSSC Brewery project is a microservices-based application designed to manage brewery operations. This project leverages Spring Boot and Spring Cloud to create a scalable and maintainable system for handling various brewery-related tasks.

# Features
Beer Inventory Management: Track and manage beer inventory levels.

Order Processing: Handle customer orders efficiently.

Brewery Services: Manage brewing processes and schedules.

Client Integration: Integrate with external clients for order and inventory management.

# Technologies Used

Java: Core language for development.

Spring Boot: Framework for building microservices.

Spring Cloud: Tools for managing microservices architecture.

Maven: Build and dependency management.

# Getting Started
To get started with the MSSC Brewery application, clone the repository and follow the setup instructions in the README.md file.
